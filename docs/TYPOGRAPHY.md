# TYPOGRAPHY

Recommended current implementation:
- Main titles: Cormorant Garamond Medium (500)
- Section headings: Cormorant Garamond SemiBold (600), readable, not cursive
- Table/body labels: Source Sans 3 Regular/Medium/SemiBold

Fallback:
- serif: Georgia
- sans: Arial

Rules:
- No handwritten/cursive section heading font.
- Do not distribute font files.
- Heading words remain live text, never baked into PNG/SVG assets.
