# MONDAY STRUCTURE LOCK

This document controls the Monday two-page functional layout.

## Page 1 only: large page heading
- large generated weekday heading, e.g. MONDAY
- generated date / term / week information
- no `Today` section

Then:
1. Appointments / Meetings
   - 3 rows minimum
   - 4 if room permits
2. Students to Follow Up
   - 3–5 rows
3. Life Skills GO
   - 5–7 rows
4. Tasks / Admin
   - 5–7 rows

## Page 2
NO second large page heading.

At top:
- compact generated day/date/term/week reference only

Then:
1. Sentrals
   - 8–12 rows
2. Calls / Email / Messages
   - 5–7 rows
3. Notes / Overflow
   - reduced to approximately half of the earlier large notes area
4. End of Day
   - Everything completed
   - Incomplete tasks moved to Friday backlog

## Default coded-reference row counts
- Appointments: 4
- Students: 5
- Life Skills GO: 6
- Tasks/Admin: 6
- Sentrals: 10
- Calls/Email/Messages: 6
- Notes: 4 ruled lines
