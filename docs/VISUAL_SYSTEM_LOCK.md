# VISUAL SYSTEM LOCK

## Look
Elegant + slightly edgy, with functional whitespace.

## Use
- warm off-white paper
- deep plum / charcoal for contrast
- mauve sparingly
- musty pink as undertone only
- fine gold curves / splatter
- pale watercolour heading backgrounds
- light tables and rules

## Do not use
- florals / leaves
- slogans / quotes / taglines
- heavy purple boxes beside headings
- heavy square table borders
- dark spreadsheet grid
- highly cursive headings
- duplicated main heading on page 2
- decorative elements that take writing space

## Heading construction
1. blank heading-wash PNG/SVG
2. live text layered above it in code
3. thin table-left strip below for the table/list area

Never bake wording into the wash asset.
