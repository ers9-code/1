# DIVIDER + FRONT COVER RULES

## Divider pages
- Background artwork only.
- No wording inside PNG/SVG.
- Intended for printable blank divider stock.
- Exact stock, size, tabs and print setup are not yet decided.
- Do not commit the planner generator to A4 divider stock.
- SVG files are scalable theme masters.
- PNG files are reference raster exports only.
- Do not crop the composition when a final stock size is chosen.
- If the final aspect ratio changes, deliberately adapt/regenerate the background master.

## Front cover
Same rules:
- blank artwork only
- no baked-in wording
- final size/material not decided
- overlay live/final cover wording separately
- preserve the full background composition
- do not crop to force-fit
